# Codex handoff

Start with [`NEXT_CODEX_HANDOFF.md`](NEXT_CODEX_HANDOFF.md), then use
[`FILE_GUIDE.md`](FILE_GUIDE.md) to locate artifacts. The checklist in
[`VALIDATION_CHECKLIST.md`](VALIDATION_CHECKLIST.md) defines the minimum
pre-action audit for any continuation.

This folder intentionally uses path variables. Create an untracked local
mapping from [`SERVER_PATHS.example.env`](SERVER_PATHS.example.env); never
commit machine-specific paths or credentials.
